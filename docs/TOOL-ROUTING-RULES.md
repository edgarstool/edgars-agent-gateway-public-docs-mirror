# Tool Routing Rules

## MCP clients

- Use: https://entry.edgars.tools/mcp
- Clients: Cursor, Windsurf, Claude Desktop, Codex, generic MCP

## Web Chat AI / Actions

- Use: https://api.edgars.tools/openapi.json
- Clients: ChatGPT Actions, Custom GPT, OpenAPI-compatible assistants

## Browser agents

- Use: https://api.edgars.tools
- Handoff docs:
  - https://api.edgars.tools/health
  - https://api.edgars.tools/v1/tools
  - https://api.edgars.tools/openapi.json
- Clients: Comet, Perplexity, Claude in Chrome, browser agents

## Code agents

- Use local project workspace:
  - V:\projects
- Do not fetch code from public docs mirror.

## Runtime / cache

- Use runtime/cache layer:
  - G:\AI_WORK_512
- Do not publish runtime artifacts.
